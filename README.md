🛡️ InternGuard

Internship Safety & Risk Analysis Assistant

InternGuard is a student-focused web application that analyzes internship offers and identifies potential risk indicators before a student proceeds.

🚨 Problem

Students often receive internship opportunities through emails, messaging apps and online platforms. Some offers may contain warning signs such as:

- Unexpected payment requests
- Unrealistic selection or job guarantees
- Urgent decision-making pressure
- Unofficial communication channels
- Requests for sensitive information
- Suspicious links

Students may not always recognize these warning signs.

💡 Solution

InternGuard allows a student to paste an internship message, email or job description into the application.

The system analyzes the text using rule-based pattern detection and generates:

- Risk Score from 0–100
- LOW / MEDIUM / HIGH Risk classification
- Detected risk indicators
- Explanation for each warning
- Suspicious link detection
- Verification checklist
- Safety recommendations

🔄 How It Works

1. User pastes an internship offer.
2. InternGuard analyzes the text.
3. Potential warning patterns are detected.
4. Risk points are assigned.
5. The total score is calculated.
6. The system displays the risk level and detected indicators.
7. The user receives verification guidance.

🎯 Target Users

Students and fresh graduates searching for internships through online platforms, emails and messaging channels.

⚠️ Disclaimer

InternGuard provides a first-level automated risk assessment based on detected patterns. A risk score does not prove that an opportunity is fraudulent. Users should independently verify the company, recruiter and internship details before proceeding.
